# IdempotentSmith Design System

Integrates 5 patterns from `DESIGN_INSPIRATION.md`:
1. **#12 Bento Grid:** Modular 12-column grid layout.
2. **#20 Dark Mode UI:** `#070a12` obsidian canvas with `#38bdf8` cyan and `#10b981` emerald accents.
3. **#10 Glassmorphism:** Translucent `backdrop-filter: blur(16px)` panels.
4. **#3 Swiss Design:** Crisp monospaced telemetry and grid alignment.
5. **#24 Cybercore:** Live SVG health gauge and race simulation bars.
